## Copy rules · Правила формулировок

- Say **Allow notification access** / **Разрешите доступ к уведомлениям** when asking for system permission.
- Use **History** / **Журнал** as the screen title. An individual item is a **history entry** / **запись журнала**. Use **event** / **событие** in engineering descriptions of posts, updates, removals, and gaps.
- A rule chooses **Hide** / **Скрыть**. Display **Removal observed** / **Удаление наблюдалось** only after Android reports removal.
- Use **Create rule from entry** / **Создать правило из записи**. Show **Import rules** and **Export rules** as separate actions.
