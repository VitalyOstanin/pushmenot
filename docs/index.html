Order updates stay. Rules hide promotions.

Notification filter and history for Android

Push Me Not can distinguish notifications from the same channel. Every notification the app receives stays in history.

Android APK Android 12 or later

The .apk file is available on GitHub. Installation steps

Notifications stay in history after dismissal

History keeps the order update and the promotion you hid. You can open the order from history while the original notification action is still available.

History and rules are stored on your device.

A rule from a notification

A notification in the shade or history can be the basis for a rule. Its condition can be edited before saving. The example rule hides a promotion from Oxygen Shop and leaves the order update in the shade.

Android posts the notification first, so a banner or sound can appear before the rule hides it.

Installation and the first rule

  1. APK installation. Installation starts with the .apk file from GitHub. The file opens on the phone. Android may request permission to install from that source.
  2. Notification access. Push Me Not needs Android notification access. This permission lets the app read notifications for filtering and history.
  3. First rule. An unwanted notification can be the basis for the first rule. Filtering for its app can be enabled when the rule is saved.

Features

  • Important alerts and hidden promotions

    Order and payment updates can stay in the shade even when the same app sends ads through the same channel.

  • All received notifications in one place

    Searchable history includes hidden notifications and notifications from unfiltered apps. It can also be narrowed to one app.

  • Actions from dismissed notifications

    An order or message can be reopened from history while the original action is available. If it is no longer available, history offers to open the sending app when possible.

  • Rules from notifications

    A card in the shade or a history entry can be the basis for a rule. Saving the rule can hide matching cards already in the shade.

  • Two filtering modes

    Each app or channel can show only notifications allowed by a rule, or hide only those blocked by a rule.

  • Conditions and repeat limits

    Rules can match the app, channel, title, text, sender or frequency. A rule can apply to one app or to all apps selected for filtering and limit how many matches stay visible in a time window.

  • Rule preview on saved notifications

    The preview shows how a draft rule would apply to saved notifications. History shows the original decision and the result under current rules.

  • History from the shade

    The Push Me Not notification opens history directly. Its availability depends on Android notification permissions.

  • Hidden notification counts

    The app shows how many of the notifications it received were hidden today and this week.

  • History storage settings

    History size and content retention are configurable, including notification text and available image previews. History and rules are stored on the device.

  • History export for analysis

    History can be exported to JSON for a chosen app and date range, with control over which data is included.

  • Rule transfer between phones

    A rules file can be saved or shared with the list of apps selected for filtering. Import can add to or replace current rules.

  • Earlier rule versions

    Every saved change creates a local version. Versions can be compared, restored or backed up together.

  • Permissions and background settings

    Settings show notification access and battery restrictions. The relevant Android settings open from the app. The interface is available in English and Russian.

  • App updates

    The app can check GitHub for new versions. The APK can be installed from the app or downloaded manually.
