Find a notification after it leaves the shade

History keeps the order update and the promotion you hid. You can open the order from history while the original notification action is still available.

History and rules are stored on your device.

Create a rule from a notification

Open a notification in Push Me Not, choose Create rule and edit the condition if needed. In this example, the rule hides promotions from Oxygen Shop and keeps the order update.

Android posts the notification first, so a banner or sound can appear before the rule hides it.

Install and get started

  1. Install the APK. Download it from GitHub and open it on your phone. Android may ask you to allow installs from this source.
  2. Grant notification access. Open Push Me Not. The permission lets it read notifications for filtering and history.
  3. Create your first rule. Choose an unwanted notification in the app and tap Create rule. If needed, turn on filtering for that app when saving.

Features

  • Keep important alerts and hide promotions

    Keep order or payment updates while hiding ads from the same app, even in the same notification channel.

  • Find all received notifications in one place

    Search history and narrow it to one app. It includes hidden notifications and notifications from apps you do not filter.

  • Reopen dismissed notifications

    Go back to an order or message from history while the original notification action is available. If it has expired, open the sending app when available.

  • Create a rule from a notification

    Use a notification still in the shade or an entry in history. A saved rule can also hide matching notifications already in the shade.

  • Show only allowed notifications or hide selected ones

    Choose a default for each app or channel. Hide everything unless a Keep rule matches, or show everything unless a Hide rule matches.

  • Build rules and limit repeats

    Match the app, channel, title, text or sender. Use rules for one app or across apps, and limit how many matching alerts to keep within a time window.

  • Preview the effect of a rule

    Test a draft on saved notifications. In history, compare the original decision with what the current rules would do.

  • Open history from the shade

    Enable the Push Me Not notification to jump straight to history from the shade.

  • See how many notifications were hidden

    View the number hidden out of all received notifications today and this week.

  • Control what history stores

    Set its size and choose whether to save notification content, including text and available image previews. History and rules are stored on your device.

  • Export history for analysis

    Choose an app and date range, then export to JSON. You can choose which content to include.

  • Move rules to another phone

    Save or share a rules file with the apps selected for filtering. Add new rules from a file or replace your current rules.

  • Restore earlier versions of your rules

    Every saved change creates a local snapshot. Compare and restore versions, or save a backup that includes all versions.

  • Manage Android permissions and background settings

    Check notification access and battery restrictions, then open the relevant Android settings from the app. The interface is available in English and Russian.

  • Check for and install updates

    Check GitHub for a new release, then install it from the app or download the APK manually.
